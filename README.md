# 행렬의 네 방

사진을 5분의 1로 줄여도 거의 같다 — 행렬이 품은 기본 공간과 랭크를 손으로 체험하는 앱입니다. 3×4 행렬을 한 단계씩 소거해 행 공간·열 공간의 기저 찾기(피벗 위치의 원래 열이라는 함정 포함), 열 공간과 Ax = b의 해, 랭크와 낮은 랭크 근사로 그림·내 사진 압축(기기 안에서 계산), 주도 변수·자유 변수와 영 공간의 기저, 차원 정리(랭크 + 영 공간 차원 = 열의 개수), 손끝을 고정한 채 팔꿈치를 돌리는 로봇 팔의 여유 자유도까지 담았습니다. 선형대수 06 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 구성
- ① 행·열 공간: 행렬 편집과 단계별 소거, 행 공간·열 공간 기저와 함정, 열 공간 직선 위 b 고르기, 퀴즈 ①
- ② 랭크·압축: 랭크 요약, 128×128 그림·줄무늬·무작위 점·내 사진의 k개 근사(저장량·오차·특잇값), 원고의 512×512 결과 표
- ③ 영 공간: 주도·자유 변수, 영 공간 기저와 A·x = 0 확인, 차원 정리 막대, 퀴즈 ②
- ④ 로봇 팔: 3관절 팔 영 공간 방향으로 장애물 피하기, 세 줄 정리, 생각해 볼 질문

※ 사진은 서버로 보내지 않고 기기 안에서만 흑백 128×128로 바꿔 계산합니다.
